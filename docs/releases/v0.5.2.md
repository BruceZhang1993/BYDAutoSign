# BYD Auto Sign v0.5.2 · 首个正式版本

比亚迪微信小程序每日签到助手。本次首次正式发布包含原生签到、自动调度及更完善的历史与问题排查功能。

## 主要功能

- **每日自动签到**：初始化授权后可设置最多 8 个签到时间，日常签到无需微信常驻。
- **手动签到与今日状态**：一键执行并显示结果，当天成功后避免重复签到。
- **签到历史与结果通知**：记录最近的签到结果，首次成功或最终失败时可通过系统通知提醒。
- **自动恢复能力**：处理部分错过的调度、网络和临时错误，改善重启、跨日期等场景下的稳定性。
- **安全与诊断**：使用 Android Keystore 加密保存授权数据，支持导出脱敏诊断报告。
- **简洁界面**：提供中文使用说明，支持浅色和深色外观。

## 安装和使用

1. 从下方 **Assets** 下载 `BYDAutoSign-v0.5.2.apk`，直接安装；这是使用固定发布证书签名的原始 APK。
2. 需要 **Android 8.0+**、已安装的微信及可运行的 **LSPosed** 环境。
3. 在 LSPosed 中启用本模块，并将微信勾选为作用域，完全重启微信。
4. 打开应用，点击「初始化并授权」，完成后再设置每天的自动签到时间。

请注意：**签到本身不需要 Root，但微信授权仍依赖 LSPosed**，部署 LSPosed 可能需要 Root 或其他系统级方案。

## 升级和已知限制

- 从旧 Root 脚本方案迁移时，请先自行停用旧定时任务，避免两套系统同时运行，并在新版中重新授权。
- 暂不支持微信分身、多账号；部分微信版本可能不兼容。
- 已验证的设备不代表所有厂商 ROM。系统省电、Doze、权限及网络条件仍可能影响执行时间。
- 如遇到问题，请通过「签到记录」和「运行诊断」排查，并在反馈时附上脱敏报告；不要公开登录凭证。

First public release of BYD Auto Sign for Android: configurable daily check-ins, one-tap check-in, sign-in history, optional result notifications, missed-schedule recovery, and privacy-conscious diagnostics.
