# BYD Auto Sign v0.5.4 · 每日调度优化与签到诊断增强

本次更新重点改善自动签到的执行规则、下次运行时间展示，以及失败原因排查。可使用本页提供的已签名 APK 从 v0.5.3 覆盖升级。

## 更新内容

- **每日一个签到时间**：在设置中选择一个每天开始签到的时间，避免多个时间点重复调度；旧版保存多个时间点时会保留最早的有效时间。
- **失败后按小时重试**：当日签到失败后约一小时再次尝试，持续到当天结束。当天签到成功或确认已签到后，不再继续调度；次日重新从设定时间开始。
- **首页展示下次执行时间**：开启自动签到后，可以直接查看下次计划执行的时间，并区分正常每日签到和失败重试。
- **更清楚的调度记录**：继续保存闹钟触发、任务入队和已签到跳过等记录，方便核对自动任务是否实际运行。
- **更完整的失败诊断**：签到失败时补充可安全显示的业务返回码、HTTP 状态和脱敏错误摘要；在签到历史及诊断导出中查看相关线索，帮助判断是否需要重新授权。

## 安装与升级

请在此页面 **Assets** 下载 `BYDAutoSign-v0.5.4.apk`，直接覆盖安装已有版本。发布流程沿用持久化的应用签名配置，通常无需清除数据或重新授权。另提供 `SHA256SUMS.txt` 供校验文件完整性。

支持 **Android 8.0 及以上**。首次微信授权或后续重新授权仍需可用的 LSPosed 环境；日常签到本身不执行 Root 命令。

> 部分设备的省电策略、后台限制以及网络状态可能使定时任务延迟；「一小时重试」表示计划间隔，不保证 Android 在指定分钟精确唤醒。若服务器拒绝签到且提示登录信息失效，可以在应用中重新授权后重试。脱敏诊断仍不应包含完整原始授权响应。
