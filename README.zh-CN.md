# BYD Auto Sign · 比亚迪自动签到

**每天自动签到，省去反复打开微信小程序的麻烦。**

BYD Auto Sign 是一款非官方的 Android 比亚迪自动签到工具。首次通过微信完成授权后，就可以按设定时间自动签到，也能随时手动签到，查看当天结果和历史记录。

[English](README.md) | **简体中文**

## 功能介绍

- **每日自动签到**：设置想要签到的时间，之后自动执行。
- **一键签到**：打开应用就能手动签到。
- **签到记录**：查看近期签到结果，失败时也能知道大致原因。
- **结果通知**：成功或最终失败时提醒；当天已经签到不会重复提醒。
- **问题诊断**：查看定时任务是否正常，并导出不包含授权凭证的排查报告。
- **简洁界面**：支持跟随系统的浅色和深色模式。

授权成功后，日常签到会使用保存在手机上的信息，**不用一直开着微信**。

## 安装前准备

- **Android 8.0 或更高版本**的手机。
- 已安装并能正常使用的**微信**，可访问比亚迪微信小程序。
- 已配置并可以正常运行的 **LSPosed** 环境。

**需要 Root 吗？** 本应用日常签到本身不使用 Root 命令，但 LSPosed 通常需要 Root 或其他兼容的系统级环境。仅安装 APK、没有可用的 LSPosed，暂时无法完成微信授权。

目前只支持**手机主用户中的微信**授权，暂不支持微信分身、多个用户和多个比亚迪账号。

## 安装方法

1. 打开 [GitHub Actions 构建页面](https://github.com/BruceZhang1993/BYDAutoSign/actions/workflows/android.yml)，选择一次成功的 **Android CI** 构建。
2. 在页面的 **Artifacts** 区域下载已签名的 `BYDAutoSign-release.apk`。下载可能需要登录 GitHub。
3. 在手机上安装 APK。如果系统提示，请允许所用的浏览器或文件管理器安装应用。
4. 打开 **LSPosed**，启用 **BYD Auto Sign** 模块，并在作用域中勾选**微信**。
5. **完全关闭微信后重新打开**，使模块生效。

如果以前用过依赖 Root 的旧版签到工具，请先看[旧版升级说明](#从旧版升级)。

## 使用方法

### 1. 初始化授权

打开 BYD Auto Sign，点击 **「初始化并授权」**。

应用可能会在这一步打开微信。看到授权成功提示后就可以使用签到功能了，**不需要每天重复授权**。

### 2. 立即签到

在首页点击 **「立即签到」**，就可以手动签到。首页会显示当天是否已签到；当天已完成后，不会再次提交签到。

### 3. 设置自动签到

进入右上角的 **「设置」**，开启 **「每日自动签到」**，输入签到时间：

- `07:01`：每天 7:01 尝试签到。
- `07:01,13:01,22:01`：每天设置多个尝试时间。

使用 24 小时制，多个时间用英文逗号分隔，最多设置 **8 个时间**。最后点击 **「保存更改」**，即可在首页看到下次计划时间。

如果系统提示允许**精确闹钟权限**，建议允许，以减少延迟。有些手机还需要适当放宽省电限制，让应用能够在后台运行。

### 4. 查看结果

首页会显示今日签到状态和最近记录。点击**「签到记录」**可查看以往结果；进入**「运行诊断」**可查看定时状态并导出排查报告。

如果希望收到签到提醒，请允许系统通知权限。关闭通知不会影响签到。

> Android 的省电机制、网络情况和不同厂商的后台限制，都可能让定时任务延后。应用会尽量补上错过的签到，但无法保证每次都精确到指定分钟。

## 常见问题

**Q：使用这个应用一定要 Root 吗？**  
签到功能本身不需要 Root，但首次微信授权依赖 LSPosed。安装 LSPosed 可能需要 Root 或其他兼容方案。

**Q：自动签到时需要让微信一直运行吗？**  
不需要。一般只有首次授权或重新授权时才需要微信参与，日常签到不要求微信常驻后台。

**Q：点击「初始化并授权」提示微信未连接怎么办？**  
检查微信是否已安装、LSPosed 模块是否启用、作用域是否勾选微信，并完全重启微信。可以先手动打开微信，再返回应用重试。部分微信版本可能暂时存在兼容性问题。

**Q：设置了自动签到，为什么到了时间却没有执行？**  
先确认自动签到已经开启，首页显示了下次执行时间；再检查网络、精确闹钟权限和手机的省电限制。可以在「运行诊断」中查看最近是否收到、执行过任务。Android 不保证后台任务绝对准时。

**Q：为什么突然需要重新授权？**  
授权信息可能过期，也可能因清除应用数据、重新安装等原因失效。进入「设置」，点击**「重新授权」**即可，无需在应用中手动填写比亚迪账号密码。

**Q：已经签到过了，还会重复签到、反复通知吗？**  
正常情况下不会。应用会跳过当天已经完成的签到，也不会在自动重试期间反复推送提醒。允许通知后，会在首次签到成功或最终失败时提醒。

**Q：支持微信分身或者多个比亚迪账号吗？**  
目前还不支持，后续版本计划逐步扩展。

**Q：我的授权信息保存在哪里？**  
授权信息加密保存在当前手机，没有云端账号同步功能。反馈问题时，请不要公开授权凭证或未经处理的原始日志。

## 从旧版升级

如果之前安装过依赖 Root 的旧版签到工具，请注意：

1. **先通过 Root 管理工具停用或移除旧的自动签到任务。** 新版不会自动清理旧任务，否则可能出现两个工具同时签到。
2. 安装新版 APK，进入应用**重新授权一次**。旧版的授权信息无法自动迁移。
3. 在设置中确认自动签到时间，并检查首页的下次执行计划。

## 问题反馈

遇到问题时，可以先查看「签到记录」和「运行诊断」。反馈时请注明手机型号、Android 版本和出现问题的步骤；必要时附上应用导出的**脱敏诊断报告**。请勿上传账号授权凭证或未经处理的服务端响应。
